# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/m-lyon/hydrust-vscode/security/advisories/new)
(the **Security** tab, then **Report a vulnerability**).

Include the affected version, the steps to reproduce the problem, and its effect.
You will get a reply when the report has been read. You will also hear about the
fix and the advisory before they are published.

For a problem in the language server itself, report it on
[m-lyon/hydra-lsp](https://github.com/m-lyon/hydra-lsp/security/advisories/new).

## Supported versions

Only the latest release gets security fixes.
